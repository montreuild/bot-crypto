## 4. Variables d'environnement ajoutées ou précisées

| Variable | Rôle |
|---|---|
| `TRUSTED_PROXIES` | IP du reverse proxy (CSV). Honorée par l'auth **et** le rate-limit. Vide = pair TCP. |
| `ALLOW_WS_QUERY_KEY=1` | Autorise `?api_key=` sur `/ws` (fuit dans les logs). Défaut : refusé. |
| `METRICS_TOKEN` | Auth scrape Prometheus ; sinon `web.api_key` si posé. |
